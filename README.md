# 叢林奇談：幼童軍互動探險 RPG

以《叢林奇談》12 篇故事為主線的幼童軍網頁遊戲。整個遊戲就是一個 `index.html`（約 0.5 MB，插畫已內嵌），用手機或電腦瀏覽器打開就能玩，不需要安裝。

遊戲網址：https://aihong-lab.github.io/CUBSCOTGAME/

## 玩法
- **自由探索**：拖曳虛擬搖桿（電腦可用 WASD／方向鍵）在森林裡自由走動，有岔路、指示牌和路標，點亮路標會擴大視野並補血。
- **小隊與天賦**：報到時選小隊和天賦（服務／體能／巧手），天賦決定整趟冒險的技能章樹，中途不能更換。
- **技能章樹**：26 枚技能章分成 3 棵 4 層分支樹，每枚章加強的能力都不同（移速、視野、星火傷害、暴擊、繩結、冷卻、回血等）。技能章不能一開始就選，要在探索、開寶箱、破關或小遊戲獲勝時隨機觸發奇遇，通過「實作闖關＋專屬問答」才會升級。
- **5 級 28 項進程**：Lv.1～4 剛入團、Lv.4 以上羚羊、Lv.10 以上狼、Lv.20 以上鹿、Lv.30 以上豹。每一項都要核章通過；沒通過可以繼續升級，但級別會停在原地，後面的故事線也會鎖住。
- **4 款小遊戲**：星火路標遠征（含 Boss 戰）、結繩拉線、八方位羅盤、金氏記憶。
- **新手教學**、完整故事書，以及可下載的榮譽證書。

## 存檔
進度只存在玩家自己的瀏覽器（localStorage），不收集任何個人資料。
