# 叢林奇談：幼童軍互動探險 RPG

以《叢林奇談》12 篇故事為主線的幼童軍網頁遊戲。整個遊戲就是一個 `index.html`（約 0.5 MB，插畫已內嵌），用手機或電腦瀏覽器打開就能玩，不需要安裝。

遊戲網址：https://aihong-lab.github.io/CUBSCOTGAME/

## 玩法
- **森林迷宮**：拖曳虛擬搖桿（電腦可用 WASD／方向鍵）自由走動（不是走格子），樹籬就是迷宮的牆。每次的迷宮都不一樣，有岔路、指示牌和路標，越後面的篇章迷宮越大（7×7 → 8×8 → 9×9）。小地圖只會顯示走過的路。
- **小隊與天賦**：報到時選小隊和天賦（服務／體能／巧手），天賦決定整趟冒險的技能章樹，中途不能更換。
- **技能章樹**：26 枚技能章分成 3 棵 4 層分支樹，每枚章加強的能力都不同（移速、視野、火把傷害、暴擊、繩結、冷卻、回血等）。技能章不能一開始就選，要在探索、開寶箱、破關或團康獲勝時隨機觸發奇遇，通過「實作闖關＋專屬問答」才會升級。
- **5 級 28 項進程**：Lv.1～4 剛入團、Lv.4 以上羚羊、Lv.10 以上狼、Lv.20 以上鹿、Lv.30 以上豹。每一項都要核章通過；沒通過可以繼續升級，但級別會停在原地，後面的故事線也會鎖住。
- **4 款團康**：路標遠征（含 Boss 戰）、結繩步驟（把平結、蝴蝶結、雙半結、接繩結、稱人結、雙套結的真正打法依順序排好）、八方位羅盤、金氏記憶。練習場不會扣主線體力。
- **手機也能玩**：地圖與團康會自動填滿螢幕，羅盤導引線沿著迷宮走道指路。
- **🐣 語音輕鬆版（推薦小一～小三）**：報到時一定要先選版本（語音輕鬆版／標準探險版），之後也能在「榮譽帶 → 冒險道具」切換。故事、題目、選項、教學、戰況、羅盤方位、金氏物品、結繩步驟與擋關說明都會唸出來（可按「🔈 再聽一次」）；結繩只要排最後 3 步，字比較大，題目變成 2 選 1，迷宮、敵人和團康也比較簡單；進程門檻和故事線規則不變。
- **插畫**：除了 4 張水彩插畫，所有角色（阿克拉、伯魯、巴希拉、卡阿、哈帝、邪漢、塔巴基、猴群、梅蘇亞、水牛、紅狗、白眼鏡蛇…）都有卡通頭像；每篇開頭有場景圖（白天／黃昏／夜晚），題目會依內容配上繩子、急救包、地圖、國旗、小黃本等小插圖。
- **🐾 小狼抉擇**：每一篇遇到任務角色時，要選出符合幼童軍規律的行動，第一次就選對可以得到蜂蜜；選錯會有提示，可以再選。
- **章節問答**：每篇 3 題，答錯的題目會移到最後再考一次。
- **新手教學**、完整故事書，以及可下載的榮譽證書。

## 存檔
進度只存在玩家自己的瀏覽器（localStorage），不收集任何個人資料。

## 效能

- Tailwind 樣式已預先編譯成內嵌 CSS，不再於手機上即時編譯（開啟更快、點按不卡）。
- 森林迷宮的草地、小徑、樹木只在進入迷宮時畫一次存成圖層，之後每格畫面直接貼上（低階手機模擬下每格繪圖由約 27ms 降到約 0.7ms）。
- 羅盤路線、技能章加成、畫面上的文字都只在有變化時才重算／更新。
