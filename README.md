# 叢林奇談：毛克利的冒險（幼童軍 RPG）

以《叢林奇談》為故事背景的幼童軍知識網頁遊戲。整個遊戲就是一個 `index.html`，不需要安裝、不需要後端，用瀏覽器打開就能玩，手機和電腦都可以。

## 玩法
- **故事模式**：12 篇冒險，從剛入團一路到豹級，每篇是一個隨機迷宮。
- **迷宮阻礙**：倒木、猴群、荊棘、迷霧、溪流、營火、貓頭鷹、小黃本檢核站，8 種阻礙對應 8 類題庫，每個阻礙要答對 5 題才能通過，而且一定擋在主路上、繞不過去。
- **隨機遭遇**：走路時可能遇到「野外小考驗」（連答 5 題，答對 3 題以上有獎勵）或「野生動物」（打贏有獎勵）。
- **問答關**：故事模式每篇結尾至少 5 題，連續闖關的問答關 10 題。
- **毛克利造型**：點左上角大頭貼，可以換膚色、髮型、表情、領巾顏色。
- **回合制戰鬥**：出擊、小隊支援（集氣）、防禦、蜂蜜補血；敵人蓄力時記得防禦。
- **🔥 連續闖關**：一關接一關，迷宮越來越大、阻礙越來越多、答題時間越來越短，會記錄最佳關數。

操作：點格子自動走、滑動或方向鍵移動；空白鍵翻對話；戰鬥 1–4；答題 1–3 或 A–C。

## 題庫
約 178 題，分 8 類（每類 22 題以上）：諾言・規律・禮節、結繩、急救、方位與地圖、露營與用火、安全守則、自然觀察、進程與技能章，每題有 ★～★★★ 難度。
題目在 `index.html` 裡的 `QUESTION_BANK`，新增題目時正確答案寫在選項第一個即可（顯示時會自動洗牌）。

## 存檔
進度與連續闖關最佳紀錄只存在玩家自己的瀏覽器（localStorage），不會收集任何個人資料。
